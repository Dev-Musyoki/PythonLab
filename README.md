# PythonLab

Python learning exercises and small practical projects.

## Contents

- Core Python practice: fundamentals, control flow, collections, functions, recursion, iterators, generators, decorators, and regular expressions.
- `matatu_app/`: object-oriented examples and a small Matatu fare and storage application.

## Run an exercise

Use Python 3 and run a selected script from this folder, for example:

```powershell
python fundamentals.py
```

For the Matatu application, start with `matatu_app/main.py` and follow the imports and prompts in that script.

These are learning exercises and are shared as-is.
